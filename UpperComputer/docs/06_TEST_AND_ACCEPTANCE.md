# 测试与验收计划

## 1. 测试金字塔

```text
少量真实机械动作（安全门后）
只读板卡 + 安装包端到端
GUI + Mock端到端
组件/集成测试
大量纯函数单元/性质/模糊测试
```

## 2. 自动测试维度

### 协议

- CRC黄金向量。
- 每个命令最小/最大/非法长度。
- 任意字节分块。
- 多帧粘连。
- 噪声、CRC错误、错误ETX、非法LEN。
- 截断和frame timeout。
- 100万级随机字节不得崩溃或越界。
- V1 60字节状态和V2逐字段编码黄金向量。
- 未知enum/flag/schema。

### Transport

- open/close幂等性。
- close取消阻塞read。
- 部分写、掉线、权限错误。
- 写队列满。
- Mock/Serial contract一致。
- 重连不重发危险命令。

### Session

- 每条合法状态迁移。
- 无效迁移。
- 握手超时。
- V1回退、V2协商。
- stale snapshot。
- seq wrap、重复、乱序、丢样。
- 危险命令unknown outcome。

### SafetyGate

每种危险命令覆盖：

- 未连接。
- 只读模式。
- capability缺失。
- 状态过期。
- FAULT/BOOT/TEACHING等状态。
- NaN/Inf/int范围。
- 单轴/整组限位。
- 速度、步长和轨迹限制。
- Arm过期。
- 重力轴支撑未确认。
- 标定缺失。

目标：核心SafetyGate语句和分支覆盖100%，并使用Hypothesis生成边界组合。

### 轨迹

- 时间非单调、重复、负时间。
- 空/单点/百万点规模。
- NaN/Inf。
- 每轴上下限边界。
- 速度、加速度。
- 插值端点保持。
- 重采样时间单调。
- 平滑不修改raw。
- 发送调度不追赶积压。

### 运动学

- URDF零位。
- 每轴单独旋转。
- 至少10个MATLAB/MuJoCo已知姿态。
- FK连续性。
- IK→FK误差。
- 多解和限位过滤。
- 不可达和奇异点。
- MCU/模型偏置映射往返。

### GUI

- 页面导航。
- ViewModel解绑后不再更新。
- 100/200 Hz快照输入。
- STOP快捷键。
- hold-to-run鼠标释放、窗口失焦、断线。
- 确认框取消。
- V1缺失字段显示Unknown。
- 长文本/错误/高DPI。
- 数据库和模型错误仍能进入诊断。

### 数据

- schema迁移。
- 中断事务恢复。
- 批量写失败。
- 导出再导入。
- 时间排序。
- 大会话查询性能。
- 数据保留删除确认。

### 打包

- 无系统Python启动。
- 所有Qt插件和STL存在。
- Mock演示。
- 串口枚举。
- 数据目录可写。
- 非ASCII Windows用户名。
- 安装、升级、卸载。

## 3. 性能测试

| ID | 场景 | 首阶段门槛 |
|---|---|---|
| PERF-001 | Mock 100 Hz状态，六轴曲线+3D | GUI P95 frame ≤25 ms |
| PERF-002 | 100 Hz状态持续30分钟 | 通信队列无增长 |
| PERF-003 | 60秒曲线窗口 | 内存稳定 |
| PERF-004 | 10万点轨迹加载 | ≤3秒，GUI可取消 |
| PERF-005 | SQLite 100 Hz记录1小时 | 无丢样或丢样明确为0 |
| PERF-006 | V1 115200只读板测 | 目标100 Hz状态，按实际链路调整 |
| PERF-007 | V2高波特率 | 200 Hz仅在误码/队列/CPU通过后 |

性能报告必须包含机器、版本、波特率、实际帧大小、均值/P95/P99，不只报“流畅”。

## 4. 稳定性

- Mock 8小时soak。
- 真板只读1～8小时soak。
- 100次连接/断开。
- 100次Mock掉线/重连。
- 反复打开/关闭3D和曲线。
- 系统睡眠/唤醒。
- 数据库磁盘满模拟。
- 固件工具不存在/退出非0/输出乱码。

## 5. 真实板卡安全测试层级

### L0：默认只读

- HELLO。
- GET_STATE。
- GET_CAPABILITIES/PING（未来）。
- 错误CRC和噪声副本。
- 复位、烧录和verify。

### L1：单轴动作

需要组装、急停、地址、方向、限位确认。每次限定：

- 非重力轴优先。
- 低速。
- 小角度。
- 观察者在场。
- 明确STOP/断电方法。

### L2：六轴/Homing/轨迹

需要全部标定和单轴通过。

### L3：TEACH松轴

需要重力轴机械支撑、制动或配重，并确认失能掩码。

```text

[ ] 3D和FK黄金姿态通过
[ ] portable包在干净Windows机器通过
[ ] installer安装/升级/卸载通过
[ ] 只读板测通过且命令审计证明无动作命令
[ ] 真实动作项按硬件状态标记通过或明确延期
[ ] 已知限制、许可证、版本和哈希完整
```

## 7. 需求追踪

最终建立：

```text
requirement_id
 -> implementation module
 -> automated test
 -> manual test
 -> release evidence
```

不能用一个笼统“端到端测试”覆盖所有安全需求。
