## 2. 待用户审批

### A-001：协议 V2

实施单元到达协议 V2 时，Agent 必须提供：

- 新旧字段表。
- 命令 ID 和端序。
- MCU RAM/FLASH 影响。
- V1 兼容和回退方案。
- 上位机迁移方案。
- 主机、sanitizer、交叉编译和只读板测计划。

用户明确回复“确认实施协议 V2”后才能修改 MCU。

### A-002：高波特率

候选为 460800 和 921600。实施前必须说明时钟误差、VCP 支持、线缆环境、
CPU/DMA负载和回退到115200的方法。

### A-003：真实电机控制

机械臂组装完成后，由用户确认：

```text
机械支撑/制动已就绪
急停可用
电机地址唯一
方向、零点、减速比和软限位已确认
允许执行指定测试及速度/角度上限
```

### A-004：拖动示教松轴

需要额外确认 J2/J3 等重力轴获得可靠支撑，并限定失能掩码。

### A-005：MCU修复计划

用户已经要求所有确认的MCU软件问题逐项修复并独立提交。当前已完成：

- `MCU-RB0`，提交`653b994`：协议组帧边界加固。
- `MCU-RB1`，提交`ebb271c`：轨迹到达后停止重复发布。

该要求不授权危险动作板测，也不自动批准协议V2具体字段。后续仍按根Agent规则
每轮一个MCU修复单元，并保持一个问题一个提交。

## 3. 默认可自主执行

- 阅读源码和参考资产。
- 修改 `UpperComputer/` 内本单元文件。
- 运行 Mock、单元、GUI、模糊和性能测试。
- 构建本地免安装包。
- 使用 HELLO/GET_STATE 做只读板测。

## 4. 不得推断的授权

- “板子已连接”不等于允许电机动作或松轴。
- “最终全部做出来”不等于允许跳过逐单元人工审查。
- “可以修改协议”不等于某个具体 V2 方案已经批准。
- 软件 STOP 不得在界面或文档中称作安全急停。
