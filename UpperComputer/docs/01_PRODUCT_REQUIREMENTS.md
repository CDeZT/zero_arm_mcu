# ZeroArm Desktop 产品需求

## 1. 产品定义

ZeroArm Desktop 是面向单机个人使用的机械臂调试与操作应用。第一目标不是
远程多人平台，而是让同一个应用完成：

```text
发现设备
 -> 验证固件和能力
 -> 观察六轴状态
 -> 安全调试
 -> 标定
 -> 手动控制
 -> 拖动示教
 -> 编辑和回放轨迹
 -> 诊断及导出数据
 -> 更新固件
```

应用必须在机械臂尚未组装时通过 Mock 完整开发和演示。真实控制功能可以进入
发行包，但硬件测试受安全门限制。

## 2. 用户目标

- 一眼判断板卡、固件、六轴和协议是否正常。
- 不写临时脚本即可发送受控命令并理解回复。
- 同时观察目标角、实际角、误差、在线状态和故障。
- 在3D模型中预览目标，避免明显错误姿态。
- 录制拖动示教数据并进行平滑、裁剪、重采样和回放。
- 保存每次调试的原始帧和解释后数据，便于复盘。
- 无板卡时模拟正常、延迟、丢帧、CRC错误和电机故障。
- 一键生成可运行的 Windows 包。

## 3. 功能需求

### 3.1 启动与连接

| ID | 需求 | 验收 |
|---|---|---|
| FR-CON-001 | 自动枚举串口并显示名称、VID/PID和历史设备 | 插拔后列表自动更新 |
| FR-CON-002 | 支持手动端口、波特率和超时 | 设置可保存 |
| FR-CON-003 | 支持 Mock 设备选择 | 无硬件可进入完整应用 |
| FR-CON-004 | 连接后执行 HELLO/能力协商/初始状态读取 | 状态机可视化 |
| FR-CON-005 | 显示 RTT、收发率、CRC错误、超时、重连次数 | 诊断页与状态栏一致 |
| FR-CON-006 | 支持自动重连和手动断开 | 不重复执行危险命令 |
| FR-CON-007 | 固件不兼容时进入只读模式 | 明确显示原因 |

### 3.2 总览和状态

| ID | 需求 | 验收 |
|---|---|---|
| FR-STA-001 | 展示 run state、fault、连接和固件版本 | 变化延迟满足性能指标 |
| FR-STA-002 | 六轴展示 target/actual/error | urad内部、deg/rad显示可切换 |
| FR-STA-003 | 展示 enabled/homed/moving/online/limit 掩码 | V1缺失字段显示未知而非0 |
| FR-STA-004 | 目标和实际状态进入带时间戳环形缓存 | UI卡顿不阻塞通信 |
| FR-STA-005 | 故障位具有中文解释、首次时间和清除记录 | 原始值可见 |
| FR-STA-006 | 快照可导出 JSON，可复制诊断摘要 | 包含版本和时间 |

### 3.3 手动关节控制

| ID | 需求 | 验收 |
|---|---|---|
| FR-JOG-001 | 单轴选择、绝对角、相对步进和六轴同步目标 | Mock端到端通过 |
| FR-JOG-002 | 每轴滑块、数值框、微调步长和速度上限 | 限位来自配置 |
| FR-JOG-003 | 目标发送前做有限值、范围、速度和状态检查 | 非法目标不出 Transport |
| FR-JOG-004 | 目标 ghost 先在3D预览，再确认发送 | 实际/目标可区分 |
| FR-JOG-005 | 连续点动使用按住运行、松开停止发送 | 窗口失焦也停止 |
| FR-JOG-006 | STOP 始终位于固定显眼位置并有快捷键 | 不被弹窗遮挡 |
| FR-JOG-007 | ENABLE/DISABLE按掩码操作且二次确认 | 重力轴失能突出警告 |
| FR-JOG-008 | 控制频率不超过固件MotionTask 50 Hz | 自动限频和合并最新值 |

## 4. 非功能需求

| ID | 需求 |
|---|---|
| NFR-001 | GUI主线程不得执行串口阻塞IO、数据库批量写入或固件烧录 |
| NFR-002 | 正常状态下目标GUI 60 FPS，通信100 Hz时无持续积压 |
| NFR-003 | 所有跨线程队列有界，状态采用latest-value或环形缓存 |
| NFR-004 | 崩溃、断线和超时不得自动重发危险命令 |
| NFR-005 | 所有线上codec、运动学、轨迹验证和安全门均可脱离GUI测试 |
| NFR-006 | 发布包不依赖Python、源码目录或桌面绝对路径 |
| NFR-007 | 日志使用PC monotonic排序，同时保存wall clock用于展示 |
| NFR-008 | 配置、轨迹和数据库schema均版本化并支持迁移 |
| NFR-009 | V1未知字段显示Unknown，不得伪造为安全正常值 |
| NFR-010 | 所有危险动作在日志中记录请求、确认、响应和最终观察状态 |

## 5. 明确不做

- 不做账号、云端权限和多人协作后台。
- 软件 STOP 不替代硬件急停。
- 第一版不声称具有经过认证的碰撞安全。
- 未经验证不直接把强化学习动作发送到真机。
- 不在GUI线程里嵌入任意Python `eval`。
- 不在机械臂未组装时伪造真实运动验收通过。
