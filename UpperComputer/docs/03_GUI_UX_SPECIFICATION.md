# GUI 与交互规格

## 1. 主窗口布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ App/设备/协议版本    连接状态    READY/FAULT    固定STOP按钮       │
├──────────────┬──────────────────────────────────────┬──────────────┤
│ 左侧导航     │ 当前页面                             │ 右侧检查器   │
│              │                                      │ 快照/事件    │
├──────────────┴──────────────────────────────────────┴──────────────┤
│ RX/TX、RTT、采样率、丢样、数据库、提示                             │
└────────────────────────────────────────────────────────────────────┘
```

- 默认窗口1440×900，最小1280×720。
- 支持深色/浅色主题，首发默认深色。
- 中文首发，字符串通过Qt翻译机制集中管理。
- STOP固定在顶栏，不随导航消失；明确标注“软件停止，非急停”。
- 页面关闭、窗口失焦、系统休眠和通信断开触发连续点动停止。

## 3. 连接页

组件：

- Transport选择：Mock / Serial。
- 端口自动发现列表、刷新按钮、VID/PID、描述。
- 波特率、超时、轮询率高级设置。
- Mock场景和随机种子。
- 连接/断开。
- 握手步骤时间线。
- 固件、协议、schema和能力表。
- 最近设备快捷入口。

连接成功前不进入控制armed状态。自动重连成功后仍保持只读。

## 4. 总览

- 大状态卡：READY/HOMING/TEACHING/RUNNING/FAULT。
- 六轴卡片：actual、target、error、状态灯。
- 3D缩略视图。
- 最近故障和事件。
- 链路健康：RTT P50/P95、实际Hz、超时、CRC、反馈年龄。
- 快捷动作：连接、保存快照、打开诊断。
- ENABLE/HOME/TEACH不放成无说明的一键快捷按钮。

## 5. 六轴监控

每轴一行：

```text
J1 | target | actual | error | velocity | current | enabled |
     homed | moving | online | limit | feedback age
```

- target/actual/error六轴曲线。
- 通道选择、自动缩放、固定范围、时间窗、暂停显示。
- 暂停只影响显示，不停止采集和记录。
- 游标读取精确设备/PC时间。
- V1缺少velocity/current/online时显示`—`和“V1未提供”。

## 6. 手动关节页

### 单轴面板

- 轴选择。
- actual只读。
- absolute target输入。
- relative step：0.01°、0.1°、1°、自定义。
- 速度百分比和绝对上限。
- slider只用于预览，发送由独立动作触发。
- 正/负连续点动使用按住按钮。

### 六轴同步面板

- 六个目标输入。
- “复制实际到目标”。
- “复位预览”。
- “验证”生成报告。
- “预览”更新ghost。
- “Arm发送”后短时间窗口内允许“发送”。

发送按钮附近展示：

```text
最终六轴角
最大单轴变化
预计时间
限位裕量
当前状态新鲜度
```

## 7. Cartesian预览

- XYZ，单位mm。
- Roll/Pitch/Yaw或四元数切换。
- Base/World/Tool坐标系。
- IK候选列表：关节值、距离、限位裕量、奇异性评分。
- 不可达原因。
- 3D target ghost和末端坐标轴。
- IK黄金测试未通过前只允许预览，不显示“发送”。

## 8. 3D工作区

- 主视图、正视、侧视、俯视、等轴测。
- 实际/目标/轨迹可见性。
- link选择检查器。
- 世界、基座、关节和工具坐标轴。
- 末端轨迹tail。
- limit/fault/offline颜色覆盖。
- 截图、重置相机、适应模型。
- 模型映射调试模式显示原始URDF角与MCU角。

## 9. 拖动示教

状态流程：

```text
IDLE
 -> 选择轴
 -> 安全清单
 -> ARMED
 -> STARTING
 -> RECORDING
 -> STOPPING
 -> REVIEW
```

RECORDING界面：

- 红色录制标志、时长、样本数、实际Hz、丢样。
- 六轴曲线和3D。
- 注释/书签按钮。
- TEACH_STOP。

REVIEW：

- 原始轨迹只读。
- 裁剪区间。
- 去毛刺阈值。
- 平滑算法与参数。
- 重采样频率。
- 原始/处理后叠加。
- 验证报告。
- 另存为轨迹。

## 10. 轨迹编辑

四联布局：

- 样本表。
- 六轴曲线。
- 时间线/关键帧。
- 3D预览。

编辑操作全部支持undo/redo。每次处理产生history条目，不覆盖raw recording。

回放流程：

```text
离线验证
 -> 状态和连接检查
 -> 复制actual为预览起点
 -> 用户Arm
 -> 倒计时3秒
 -> PLAYING
 -> PAUSED / STOPPED / COMPLETED / ABORTED
```

断线、FAULT、状态过期或超出跟随误差阈值时进入ABORTED，不自动续播。

## 11. 标定与Homing

逐轴向导：

1. 读取当前配置。
2. 确认唯一电机地址。
3. 确认正方向。
4. 确认减速比。
5. 建立机械零点。
6. 确认最小/最大软限位。
7. 确认最大速度。
8. 检查限位输入。
9. 保存候选配置。
10. 对比、审批、写入。

每步显示“当前已知事实、准备执行动作、风险、回退”。机械臂未组装时仅能在
Mock演练。

## 12. 诊断页

- 链路统计卡。
- 原始帧滚动表。
- 请求跟踪表。
- 状态新鲜度。
- MCU fault和逐轴诊断。
- UART/CAN错误计数。
- 数据库写入健康。
- 线程/队列长度。
- 诊断包导出。

Frame表字段：

```text
PC time | monotonic | direction | CMD | seq | length |
CRC | parse result | latency | HEX
```

## 13. 协议终端

- 默认“安全模式”：只可选择只读命令。
- 表单式字段编辑，不要求用户手工计算CRC。
- HEX预览。
- 发送、响应解析和黄金帧对照。
- 切换危险模式必须经过SafetyGate和当前测试审批。
- 不提供任意shell命令入口。

## 14. 会话、日志和数据集

- 会话列表、时间、设备、固件、时长、样本、故障。
- 多会话对比曲线。
- 原始帧和状态导出。
- 数据集Episode管理、成功/失败/备注标签。
- 相机、力传感器等未来流用统一time source字段预留。

## 15. 固件升级

- 工具路径检查。
- 固件文件、大小、SHA-256、构建信息。
- 目标设备和ST-Link SN。
- 明确的“仅刷写本设备”确认。
- 进度日志。
- verify结果。
- reset后HELLO验证。

## 16. 设置

- 外观和显示单位。
- 串口默认值和刷新率。
- 数据库位置/大小。
- 模型资源和映射。
- 图表性能。
- 手柄映射。
- STM32工具路径。
- 日志等级。
- 恢复默认值。

安全armed状态永远不写入持久设置。

## 17. 快捷键

| 快捷键 | 动作 |
|---|---|
| Space | 软件STOP（输入框聚焦时也有效，实施时评估冲突） |
| Ctrl+L | 连接页 |
| Ctrl+D | 诊断页 |
| Ctrl+R | 开始/停止本地数据记录，不直接TEACH |
| Esc | 取消Arm、关闭确认、停止连续点动 |

快捷键必须有测试；STOP快捷键不能因子控件吞键而失效。
