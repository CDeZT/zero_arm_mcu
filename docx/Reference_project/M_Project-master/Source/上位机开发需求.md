#### 参数读取（P1）

**批量读取**：
- 读取全部系统状态（0x20）
- 读取全部 PID（0x2A）
- 读取驱动配置（0x30）
- 读取回零参数（0x31）

**单项读取**：
- 读电压（0x21）、电流（0x22）、速度（0x23）、位置（0x24）
- 读位置误差（0x25）、编码器值（0x26）、温度（0x27）
- 读电机状态标志（0x28）、回零+电机状态（0x29）

**数据解析**（参考 `protocol_spec.md` §11、§12）：
```python
# 伪代码
def parse_read_response(cmd, data):
    if cmd == 0x21:  # 总线电压
        voltage_raw = struct.unpack('>H', data)[0]
        return voltage_raw / 10.0  # 0.1V → V
    elif cmd == 0x22:  # 相电流
        return struct.unpack('>H', data)[0]  # mA
    # ... 其他参数
```

**验收标准**：
- [ ] 所有读取命令正确发送

## 6. 数据处理与通信

### 6.1 帧构建与解析

**直接复用 `protocol_spec.md` §9 和 §10 的代码**：
- CRC8 表和 `crc8()` 函数
- `build_frame(cmd, data)` 函数
- `parse_frame(raw)` 函数

### 6.2 串口接收处理

**接收线程**：
```python
# 伪代码
class SerialThread(threading.Thread):
    def run(self):
        buf = b''
        while self.running:
            chunk = self.serial.read(256)
            if chunk:
                buf += chunk
            # 扫描帧
            i = 0
            while i < len(buf) - 3:
                if buf[i] == 0xAA:
                    plen = buf[i+1]
                    end = i + plen + 4
                    if end <= len(buf) and buf[end-1] == 0x55:
                        frame = parse_frame(buf[i:end])
                        if frame:
                            self.queue.put(frame)
                        buf = buf[end:]
                        i = 0
                        continue
                i += 1
```

### 6.3 事件处理

**主线程定时器**：
```python
# 伪代码
def process_queue(self):
    try:
        while True:
            frame = self.queue.get_nowait()
            self.handle_frame(frame)
    except queue.Empty:
        pass
    self.after(50, self.process_queue)  # 每 50ms 处理一次
```

## 12. 常见问题与解决思路

### Q1: 串口数据接收不完整怎么办？
**思路**：使用环形缓冲区，逐字节扫描帧头 0xAA，完整帧才解析

### Q2: 界面卡顿怎么办？
**思路**：串口接收用独立线程，通过队列传数据，主线程定时处理

### Q3: 如何验证数据解析正确？
**思路**：对照 `protocol_spec.md` 的示例帧，手动构造测试数据验证

### Q4: 如何处理命令超时？
**思路**：发送命令后启动 500ms 定时器，超时未收到响应则提示
